# YourDreamReader Studio

Android-приложение для чтения коротких новелл. Приложение работает офлайн: истории, избранное, профиль и прогресс хранятся локально на устройстве.

## Возможности
- Первоначальная настройка и редактирование псевдонима автора.
- Библиотека из пяти демонстрационных новелл и пяти жанров.
- Поиск по названию, жанру и описанию; фильтрация по жанрам.
- Карточки историй, содержание и чтение глав с переходом вперёд/назад.
- Избранное и продолжение чтения с последней открытой главы.
- Сохранение прогресса и настроек на устройстве.
- Розовое, градиентное и тёмное оформление; изменение размера текста.
- Экспорт и восстановление локальной резервной копии в формате JSON.
- Android WebView wrapper, min SDK 23.

## Сборка APK
Откройте проект в Android Studio или выполните `gradle assembleDebug`. GitHub Actions собирает debug APK при push в `main`; архив сборки публикуется как workflow artifact `YourDreamReader-Studio-debug-apk`.

## Что пока не реализовано
Это автономная MVP-версия. В ней пока нет облачной синхронизации, регистрации и входа, серверной публикации историй, полноценного редактора/конструктора новелл, переводов интерфейса и подписанного release APK. Все пять историй — демонстрационные короткие версии на русском языке.
